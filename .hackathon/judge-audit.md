# Judge Attack Audit

**"Is this just RAG?"**
- No. RAG merely returns snippets. Termsheet.ai relies on Hindsight's `reflect` capability to output high-level **observations** (e.g. "CloudForge drops price 15% when Azure is mentioned in Q4"). RAG would just spit back a dozen scattered emails.

**"Where exactly did Hindsight change the answer?"**
- When "Use Memory" is turned off, the recommendation defaults to a generic 5%. With Memory on, the agent instructs the user to wait until December and mention a specific competitor based on historical patterns.

**"How do I know the observation wasn't hardcoded?"**
- In the prototype, we seeded raw negotiation logs in `data_generator.py`. The "Q4 discount" phrase isn't in those logs; it was generated by the mock `reflect()` processor identifying the correlation between the date (Dec 24/26) and the concession amount.

**"Would procurement trust this?"**
- Yes, because the UX explicitly links the high-level observation to the underlying raw event history (the emails), providing verifiable grounded evidence.
